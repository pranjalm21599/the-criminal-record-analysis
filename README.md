# the criminal record analysis 
We propose an AI-powered Criminal Network Analysis System that brings information from FIRs, call records, financial transactions, surveillance reports, social media, and criminal records into one platform. The system will use AI and NLP to find important information such as people, phone numbers, vehicles, bank accounts, locations, organizations, and events from different types of records. It will identify when different records refer to the same person or entity and connect related information. A knowledge graph will show these connections clearly, helping investigators find hidden links between people, cases, locations, vehicles, and financial activities. The system will also analyze the network to find important individuals, groups, unusual activities, and changes over time. An interactive dashboard will provide network graphs, timelines, maps, case details, and evidence-based relationship tracking. An AI assistant will allow investigators to ask questions about the network and receive clear answers supported by the available evidence. The system will support investigators in making informed decisions.
